# ETL fixtures

Generated by `tools/ingest/ingest_mised.py --emit-fixtures`. These are trimmed,
real documents from the transform pipeline, used by `MisedDocumentMappingTest` on
the Java side to catch drift between the Python transform and the Java POJOs.

- `meeting_Bmr019.json` — the ground-truth cross-check meeting: its dialog turn
  "What did Professor B recommend to do during the discussion of digits?" cites
  segments 108, 118, 189, 224, 327. `AttributionResolver` and the UI highlighter
  must agree on exactly this set.
- `meeting_sample_ami.json`, `meeting_sample_parliament.json` — one meeting from
  each of the other two corpora, to exercise `classify()` in both languages.
- `dialogs_sample.json` — dialogs covering the proto3-omission edge cases: an
  unanswerable turn (`isUnanswerable` absent = false, present = true), a
  context-dependent turn, and the gold Bmr019 attribution above.

Do not hand-edit these files — regenerate them via the ingest CLI so they stay a
faithful snapshot of what the ETL actually produces.
